  - Інтерактивна 24-годинна шкала зі статусами (світло є / відключення / напівгодина).
  - Перемикач режимів перегляду: *«Сьогодні»*, *«Завтра»*, *«Обидва дні»*, а також стан *«Без відключень»*.
- 🏙 **Пошук черги для м. Київ за адресою (YASNO)**:
  - Пряма інтеграція з базою адрес YASNO для швидкого пошуку серед усіх **60 груп** Києва (`1.1`, `2.1` ... `60.1`).
  - Зручний пошук вулиць з автодоповненням.
  - Наочна інтерактивна сітка номерів будинків без зайвих випадаючих списків.
  - Автоматичне застосування знайденої черги та адреси в налаштування одним кліком.
- 🎨 **11 готових стилів та шаблонів**:
  1. *СвітлоБот 🗓* — класичний стиль із емодзі календаря та форматом `6:00 - 12:00`.
  2. *Класичний ДТЕК 🔖* — вигляд за інструкцією автора бота з маркерами `▪️`.
  3. *Сучасний СвітлоБот ⚡* — естетичний стиль з блискавками та моноширинним часом.
  4. *Мінімалістичний & Чистий •* — лаконічний маркований список без зайвих значків.
  5. *Яскравий зі статусами 🔴/🟢* — максимальний контраст з маркерами `❌` та `🟢`.
  6. *Київ YASNO Style 🏙* — стилістика столичних каналів з номером черги.
  7. *Компактний Годинник ⏱* — компактні рядки для мобільних пристроїв.
  8. *Офіційний Оповісник 📢* — строгий тон для новинних каналів громад.
  9. *Для ЖК / Будинку 🏢* — для чатів ОСББ, будинкових систем та ліфтів.
  10. *Енергетичний Батарейка 🔋* — тематичний дизайн з іконками живлення `🔋`/`🪫`.
  11. *Ультракороткий телетайп 📟* — стислий формат для швидких оновлень.
- 🧪 **Безпечний режим тестування (`this`)** — перевірка роботи команд у приватних повідомленнях бота без публікацій у реальний канал.
- 💾 **Автоматичне збереження** — усі зміни зберігаються у локальній пам'яті браузера (`localStorage`).
- 🌐 **Повна підтримка GitHub Pages** — проєкт працює з коробки на будь-якому піддомені чи репозиторії завдяки відносним шляхам.

## 🚀 Встановлення та запуск локально

### Вимоги
- [Node.js](https://nodejs.org/) версії 18 або новіше
- [npm](https://www.npmjs.com/)

### Кроки

1. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/<ваш-юзернейм>/<назва-репозиторію>.git
   cd <назва-репозиторію>
   ```

2. Встановіть залежності:
   ```bash
   npm install --legacy-peer-deps
   ```

3. Запустіть сервер розробки:
   ```bash
   npm run dev
   ```
   Сайт буде доступний за адресою `http://localhost:3000`.

4. Запуск тестів:
   ```bash
   npm test
   ```

5. Збірка для продакшну:
   ```bash
   npm run build
   ```

## 📦 Розгортання на GitHub Pages

У репозиторії вже повністю налаштовано автоматичне розгортання:

### Спосіб 1: Автоматично через GitHub Actions (Рекомендовано)
1. Запушіть код у гілку `main` або `master` вашого репозиторію на GitHub.
2. Відкрийте репозиторій на GitHub ➔ **Settings** ➔ **Pages**.
3. У розділі **Build and deployment** у полі **Source** виберіть **GitHub Actions**.
4. GitHub автоматично виконає workflow `.github/workflows/deploy.yml` і опублікує сайт.

### Спосіб 2: Вручну через гілку `gh-pages`
Виконайте команду:
```bash
npm run deploy
```
Скрипт автоматично збере проєкт і завантажить вміст папки `dist` у гілку `gh-pages`.
